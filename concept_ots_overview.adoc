= Conoce ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select es una versión de ONTAP exclusivamente de software que puedes implementar como máquina virtual en un host hipervisor. Complementa el conjunto de soluciones FAS, AFF y ASA de ONTAP convencionales, así como otras opciones exclusivamente de software como Cloud Volumes ONTAP.

ONTAP Select convierte unidades de disco internas, NVMe, SSD o HDD, y almacenamiento externo de cabina en un sistema de almacenamiento flexible con muchas de las mismas ventajas que ofrecen los sistemas de almacenamiento ONTAP dedicados. También puedes implementar ONTAP Select en servidores nuevos o en tu infraestructura de servidores existente. ONTAP Select es fácil de administrar y utiliza el mismo software de gestión que las soluciones basadas en ONTAP, lo que significa menos carga operativa y menos requisitos de capacitación.

ONTAP Select se adapta a tus necesidades de consumo de capacidad con dos modelos de licencia complementarios: Capacity Tiers y el completamente flexible Capacity Pools. Ambos modelos de licencia te permiten aumentar la capacidad en incrementos de tan solo 1TB. Por ejemplo, puedes empezar con unos pocos terabytes y agregar capacidad dinámicamente a medida que tu proyecto crece. Si usas Capacity Pools, puedes redistribuir la capacidad como prefieras cuando tu proyecto termine.

ONTAP Select está integrado en marcos de gestión de nube como VMware vSphere y Kernel-based Virtual Machine (KVM). Esto ayuda a acelerar el despliegue de nuevos proyectos como servicios de archivos, directorios personales, entornos de desarrollo de software y pruebas de aplicaciones.

SnapMirror software te permite mover datos entre el almacenamiento de ONTAP en la nube híbrida para que puedas acceder fácilmente a tus datos donde los quieras. Por ejemplo, puedes configurar rápidamente un entorno para probar una idea. Después, puedes mover el proyecto a una plataforma de almacenamiento dedicada para el despliegue en producción o hacerlo más accesible en la nube como parte de un flujo de trabajo de desarrollo.



== Almacenamiento definido por software

La implementación y entrega de servicios de TI mediante software permite a los administradores aprovisionar recursos con una rapidez y agilidad que antes no era posible. A medida que los centros de datos modernos migran a una arquitectura de infraestructura definida por software (SDI), puedes separar los activos de TI más valiosos de la infraestructura física subyacente, lo que proporciona flexibilidad, escalabilidad y programabilidad.

En un mundo de productos básicos donde los datos se fragmentan en silos de almacenamiento de conexión directa (DAS), la movilidad de datos y la gestión de datos se han convertido en problemas más complejos. El almacenamiento definido por software (SDS) ha surgido como una parte importante del panorama de SDI para abordar estos y otros problemas.

ONTAP Select es la solución de NetApp para el mercado de SDS. ONTAP Select aporta funcionalidades de gestión de almacenamiento para la gran empresa al centro de datos definido por software y extiende la arquitectura NetApp Data Fabric a los casos de uso más extremos, incluyendo el Internet de las Cosas (IoT) y los servidores tácticos.



== Dos componentes de software

ONTAP Select se compone de dos componentes de software principales:



=== Nodo de ONTAP Select

Un clúster ONTAP Select se compone de uno, dos, cuatro, seis, ocho, diez o doce nodos. Cada nodo del clúster se implementa como una máquina virtual independiente y ejecuta una versión especialmente diseñada del software ONTAP 9.



=== Utilidad de administración ONTAP Select Deploy

La utilidad de administración Deploy se empaqueta e instala como una máquina virtual Linux independiente. Debes usar la utilidad para implementar clústeres ONTAP Select en un entorno de producción. Una versión actual de la imagen del nodo ONTAP Select viene incluida con la utilidad Deploy.


NOTE: La utilidad de administración Deploy no tiene un número de versión independiente. Deploy tiene el mismo número de versión que la versión de ONTAP Select asociada. Sin embargo, cada actualización de la utilidad Deploy dentro de una versión específica de ONTAP Select tiene un número de compilación único.

== FlexCache write-back con ONTAP Select

ONTAP Select admite los volúmenes de caché FlexCache con write-back. El rendimiento general de la instancia de ONTAP Select es comparable al de un sistema ONTAP básico.

FlexCache los volúmenes de caché con write-back tienen los siguientes requisitos con ONTAP Select:

* Usa ONTAP Select en una instancia mediana (8 núcleos) o grande (16 núcleos).
* Usa unidades de estado sólido respaldadas por NVMe. El almacenamiento respaldado por SAS tiene un rendimiento inferior en comparación con el almacenamiento respaldado por NVMe para ONTAP Select.
* Prueba ONTAP Select para FlexCache write-back antes de iniciar el despliegue. FlexCache write-back no se recomienda para un gran número de archivos pequeños.


ONTAP Select no soporta volúmenes de caché FlexCache con write-back en una instancia pequeña (4-core). Además, ONTAP Select no soporta volúmenes de origen FlexCache con write-back en instancias pequeñas, medianas o grandes.

link:https://docs.netapp.com/us-en/ontap/flexcache-writeback/flexcache-write-back-guidelines.html["Conoce ONTAP FlexCache write-back"^]



== Compara ONTAP Select y ONTAP 9

Tanto ONTAP basado en hardware como ONTAP Select ofrecen soluciones de almacenamiento para la gran empresa. Sin embargo, debido a que están diseñados e implementados de manera diferente, cada uno puede satisfacer distintos requisitos empresariales y escenarios de uso. Deberías familiarizarte con las principales diferencias entre las plataformas antes de planificar una implementación de ONTAP Select.



=== Arquitectura HA diferente

Dependiendo del número de nodos que definas en un clúster, ONTAP Select proporciona una capacidad de HA. Por ejemplo, un clúster de cuatro nodos consta de dos pares de HA. La arquitectura de HA utilizada con ONTAP Select se basa en un modelo de almacenamiento no compartido. Es decir, un nodo en un par de HA no puede acceder directamente al almacenamiento que pertenece al otro nodo. Este diseño puede afectar ciertas características operativas de ONTAP Select.



=== Licencias de capacidad

ONTAP Select introduce un modelo de licencia basado en el consumo. Debes adquirir una licencia con capacidad de almacenamiento para cada nodo o un grupo de capacidad compartida al implementar un clúster ONTAP Select en un entorno de producción. Usando la utilidad Deploy, debes aplicar los archivos de licencia que establecen la capacidad de almacenamiento para los nodos del clúster.



=== Licencias de funciones de ONTAP

Cada nodo de un clúster ONTAP Select recibe automáticamente una licencia para usar varias funciones de ONTAP. No necesitas instalar ni aplicar manualmente estas licencias de funciones.



=== Funciones de ONTAP no compatibles con ONTAP Select

Varias funciones de ONTAP no son compatibles con ONTAP Select. En la mayoría de los casos, estas funciones requieren hardware especial que no está disponible en el entorno virtualizado de ONTAP Select.

* Actualizaciones automáticas para la protección autónoma contra ransomware (ARP)
+

NOTE: A partir de ONTAP Select 9.16.1, se admiten las actualizaciones manuales de ARP y la licencia de la función ARP está incluida en el NetApp License File (NLF).

* Espacio IP del clúster
+
No se admite ninguna modificación del espacio IP del clúster, incluyendo la adición o eliminación de puertos, VLAN o grupos de agregación de enlaces.

* Fibre Channel
+
Fibre Channel y Fibre Channel over Ethernet no son compatibles.

* Monitores de salud
+
El monitoreo de estado tradicional utilizado en una implementación de ONTAP basada en hardware es específico de los componentes de hardware subyacentes. Debido al entorno virtualizado utilizado con ONTAP Select, los monitores de estado no están activos.

* Grupos de interfaces
+
Los grupos de interfaz no son compatibles.

* Administrador de claves multiusuario (MTKM)
* Compatibilidad con descarga de NIC
+
Debido al entorno virtualizado utilizado con ONTAP Select, la función de descarga de NIC no es compatible.

* NetApp unidades de cifrado de almacenamiento
* Propiedades del puerto ONTAP
+
No se admite la modificación de las propiedades de los puertos ONTAP, incluyendo la velocidad, el modo dúplex y el control de flujo.

* Procesadores de servicios
* Migración SVM
* SnapLock Compliance
* SnapMirror active sync
* VMware HCX
