= Terminología y conceptos clave de ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Cuando empiezas a explorar ONTAP Select y a planificar un despliegue, es útil primero familiarizarte con la terminología y los conceptos clave.

ONTAP Select Deploy:: ONTAP Select Deploy es la utilidad de administración que tú usas para desplegar clústeres ONTAP Select. La utilidad Deploy se ejecuta en una máquina virtual Linux dedicada. Puedes acceder a la utilidad Deploy a través de la interfaz de usuario web, la shell de gestión de la línea de comandos y la API de REST.
Máquina virtual basada en el kernel:: Kernel-based Virtual Machine (KVM) es una característica de virtualización del kernel de Linux, que le permite actuar como una plataforma de hipervisor. Es compatible con una amplia gama de sistemas operativos invitados.
Host del hipervisor frente a nodo ONTAP Select:: Un _host de hipervisor_ es la plataforma de hardware central que aloja una máquina virtual ONTAP Select. Cuando una máquina virtual ONTAP Select está desplegada y activa en un host de hipervisor, se considera que es un _nodo ONTAP Select_.
Clúster ONTAP Select:: Puedes crear un clúster _ONTAP Select_ compuesto por uno, dos, cuatro, seis, ocho, diez o doce nodos. Los clústeres de varios nodos siempre contienen uno o más pares de HA. Por ejemplo, un clúster de cuatro nodos consta de dos pares de HA. Un clúster de un solo nodo no proporciona capacidad de HA.
Preparación del entorno del host hipervisor:: Antes de utilizar la utilidad de administración Deploy para desplegar un clúster de ONTAP Select, necesitas preparar los hosts de hipervisor donde se ejecutará ONTAP Select, incluidos los entornos de almacenamiento y redes. Esta preconfiguración del host se realiza fuera del producto ONTAP Select según los requisitos y limitaciones actuales.
Evaluación frente a despliegues de producción:: Cada nodo de ONTAP Select funciona con una _licencia de evaluación_ o una _licencia comprada_. Una licencia de evaluación te permite evaluar ONTAP Select antes de desplegarlo en un entorno de producción. La licencia de evaluación se genera y aplica automáticamente. Si despliegas un clúster en un entorno de producción, debes adquirir una licencia, lo que implica elegir:
+
--
* Modelo de licencia
* Capacidad de almacenamiento
* Oferta de licencias de plataforma


--
Modelo de licencia Capacity Tiers:: El modelo de licencia Capacity Tiers es la opción original a la hora de conceder licencias de almacenamiento para una implementación de ONTAP Select. Se basa en el modelo de ONTAP utilizado con NetApp AFF y FAS. Se requiere una licencia independiente para cada nodo. La capacidad de almacenamiento está bloqueada en el nodo y es perpetua (no requiere renovación).
Modelo de licencia Capacity Pools:: El modelo de licencias Capacity Pools se introdujo con ONTAP Select 9.5 usando Deploy 2.10. Se requiere una licencia independiente para cada Capacity Pool de almacenamiento. La licencia Capacity Pool está bloqueada en una instancia de License Manager (es decir, una instancia de Deploy) y debe renovarse según los términos de tu compra. Puedes obtener licencias y usar cualquier número de Capacity Pools en tu organización. Sin embargo, como los Capacity Pools son compartidos por los nodos ONTAP Select, normalmente se requieren menos licencias que con el modelo de licencias Capacity Tiers.
Gestor de licencias:: El administrador de licencias es un componente de software que admite licencias de Capacity Pools. Actualmente forma parte de la utilidad de administración Deploy. LM alquila almacenamiento a los nodos ONTAP Select desde los pools compartidos que gestiona. El _License Lock ID_ es una cadena numérica que identifica de forma exclusiva cada instancia de LM y, por lo tanto, cada instancia de Deploy. Debes usar tanto el número de serie de la licencia de Capacity Pool como el LLID para generar un archivo de licencia.
Ofertas de licencias de plataforma:: Existen tres ofertas de licencia disponibles que determinan las capacidades de tamaño de la máquina virtual ONTAP Select al adquirir una licencia:
+
--
* Estándar
* Premium
* XL Premium


--


Para más información, consulta las dos secciones link:concept_workflow_deploy.html["Planificar"] y link:concept_lic_evaluation.html["Licencia"].

Grupos de almacenamiento frente a almacenes de datos:: Un _storage pool_ de ONTAP Select es un contenedor de datos lógicos diseñado para abstraer y ocultar el almacenamiento físico subyacente. Un pool de almacenamiento es independiente del hipervisor. Cuando se despliega en un host de hipervisor ESXi, el _storage pool_ de ONTAP Select es sinónimo del _datastore_ de VMware.
MTU de clúster:: Cluster MTU es una función que te permite configurar el tamaño de MTU usado en la red interna con un clúster multinodo ONTAP Select. La utilidad de administración Deploy ajusta el tamaño de MTU mientras configuras los pares de HA para adaptarse a tu entorno de red. También puedes establecer el valor manualmente.
ONTAP Select vNAS:: La solución ONTAP Select vNAS permite a un nodo ONTAP Select acceder a almacenes de datos VMware en almacenamiento externo. Con ONTAP Select vNAS, ya no es necesaria una controladora RAID local; se asume que la funcionalidad RAID la proporciona el almacenamiento remoto. ONTAP Select vNAS puede configurarse de las siguientes formas:
+
--
* VMware vSAN
* Conjunto de almacenamiento externo genérico


--


En ambos casos, el almacenamiento externo debe configurarse antes de crear un clúster ONTAP Select o de ampliar la capacidad de almacenamiento de un nodo existente.

Realojamiento del nodo en la VM ESXi:: Cuando despliegas un clúster que utiliza almacenamiento externo disponible a través de la solución ONTAP Select vNAS (ya sea VMware vSAN o un array de almacenamiento externo genérico), la máquina virtual ESXi que aloja el nodo ONTAP Select puede moverse mediante acciones que utilizan las siguientes funcionalidades de VMware:
+
--
* vMotion
* Alta disponibilidad (HA)
* Programador de recursos distribuidos (DRS)
+
La utilidad ONTAP Select Deploy detecta el movimiento de la máquina virtual como parte de la ejecución de una operación en el cluster, como:

* clúster en línea
* clúster fuera de línea
* agregar almacenamiento
+
Cuando se mueve una máquina virtual, la utilidad Deploy actualiza su base de datos interna y configura el nuevo host ESXi. Todas las acciones realizadas en el nodo ONTAP Select se bloquean hasta que se completa el movimiento de la máquina virtual y las actualizaciones de Deploy.



--
Abre vSwitch para KVM:: Open vSwitch (OVS) es una implementación de software de un conmutador virtual compatible con múltiples protocolos de red. OVS es de código abierto y está disponible de acuerdo con la Licencia Apache 2.0.
Servicio de mediación:: La utilidad ONTAP Select Deploy incluye un servicio mediador que se conecta a los nodos de los clústeres de dos nodos activos. Este servicio supervisa cada par de HA y ayuda a gestionar los fallos.



CAUTION: Si tienes uno o más clústeres de dos nodos activos, la máquina virtual de ONTAP Select Deploy que administra los clústeres debe estar ejecutándose en todo momento. Si la máquina virtual de Deploy se detiene, el servicio de mediador no está disponible y se pierde la capacidad de HA para los clústeres de dos nodos.

MetroCluster SDS:: MetroCluster SDS es una función que proporciona una opción de configuración adicional al desplegar un clúster de dos nodos ONTAP Select. A diferencia de un despliegue ROBO típico de dos nodos, los nodos MetroCluster SDS pueden estar separados por una distancia mucho mayor. Esta separación física permite casos de uso adicionales, como la recuperación ante desastres. Debes tener una licencia premium o superior para usar MetroCluster SDS. Además, la red entre los nodos debe soportar un requisito mínimo de latencia.
Almacén de credenciales:: El almacén de credenciales de Deploy es una base de datos segura que contiene credenciales de cuentas. Se utiliza principalmente para registrar hosts de hipervisor como parte de la creación de un nuevo clúster. Consulta la sección link:concept_workflow_deploy.html["Planificar"] para más información.
Eficiencia del almacenamiento:: ONTAP Select proporciona opciones de eficiencia de almacenamiento similares a las opciones de eficiencia de almacenamiento presentes en las matrices FAS y AFF. Conceptualmente, ONTAP Select con SSDs de almacenamiento de conexión directa (DAS) (usando una licencia premium) es similar a una matriz AFF. Las configuraciones que usan DAS con HDDs y todas las configuraciones vNAS deben considerarse similares a una matriz FAS. La principal diferencia entre las dos configuraciones es que ONTAP Select con SSDs DAS admite deduplicación en línea a nivel de agregado y deduplicación en segundo plano a nivel de agregado. Las opciones restantes de eficiencia de almacenamiento están disponibles para ambas configuraciones.
+
--
Las configuraciones predeterminadas de vNAS habilitan una función de optimización de escritura conocida como registro de datos de instancia única (SIDL). Con ONTAP Select 9.6 y versiones posteriores, las funciones de eficiencia de almacenamiento en segundo plano de ONTAP están calificadas con SIDL habilitado. Consulta la sección link:concept_stor_concepts_chars.html["Inmersión profunda"] para más información.

--
Actualización del clúster:: Después de crear un clúster, puedes hacer cambios en la configuración del clúster o de la máquina virtual fuera de la utilidad Deploy usando las herramientas de administración de ONTAP o del hipervisor. También puedes migrar una máquina virtual, lo que provoca cambios en la configuración. Cuando ocurren estos cambios, la utilidad Deploy no se actualiza automáticamente y puede quedar desincronizada con el estado del clúster. Puedes usar la función de actualización de clúster para actualizar la base de datos de configuración de Deploy. La actualización de clúster está disponible a través de la interfaz de usuario web de Deploy, la línea de comandos de gestión CLI y la API de REST.
RAID por software:: Cuando se utiliza almacenamiento de conexión directa (DAS), la funcionalidad RAID se proporciona tradicionalmente a través de una controladora RAID de hardware local. En su lugar, puedes configurar un nodo para usar _software RAID_, donde el nodo ONTAP Select proporciona la funcionalidad RAID. Si usas software RAID, ya no necesitas una controladora RAID de hardware.


[[ontap-select-image-install]]
Instalación de la imagen ONTAP Select:: La utilidad de administración Deploy contiene una única versión de ONTAP Select. La versión incluida es la más actual disponible en el momento del lanzamiento. La función de instalación de imágenes de ONTAP Select te permite añadir versiones anteriores de ONTAP Select a tu instancia de la utilidad Deploy, que luego puedes usar al desplegar un clúster de ONTAP Select. Consulta link:task_cli_deploy_image_add.html["Agrega imágenes de ONTAP Select para más información"].



NOTE: Sólo debes añadir una imagen de ONTAP Select con una versión anterior a la versión original incluida con tu instancia de Deploy. No se admite añadir versiones posteriores de ONTAP Select sin actualizar también Deploy.

Administrar un clúster ONTAP Select después de que se haya implementado:: Después de desplegar un cluster ONTAP Select, puedes configurar el cluster como lo harías con un cluster ONTAP basado en hardware. Por ejemplo, puedes configurar un cluster ONTAP Select usando System Manager o la interfaz de línea de comandos estándar de ONTAP.
