[role="lead"]
Debes definir una cuenta de servidor vCenter y asociarla con un rol que contenga los privilegios administrativos necesarios.


NOTE: También necesitas el nombre de dominio completo o la dirección IP del servidor vCenter que gestiona los hosts de hipervisor ESXi donde está desplegado ONTAP Select.

A continuación se presentan los privilegios de administración mínimos necesarios para crear y gestionar un clúster ONTAP Select.

* Actualizar los archivos de la máquina virtual
* Actualizar metadatos de máquina virtual
