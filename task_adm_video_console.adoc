= Accede a la consola de vídeo ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puedes acceder a la consola de vídeo de la máquina virtual del hipervisor donde se ejecuta ONTAP Select.

.Acerca de esta tarea
Es posible que necesites acceder a la consola de la máquina virtual para solucionar un problema o cuando el soporte de NetApp te lo pida.

.Pasos
. Accede al cliente de vSphere y haz Sign in.
. Navega hasta la ubicación apropiada en la jerarquía para localizar la máquina virtual ONTAP Select.
. Haz clic con el botón derecho en la máquina virtual y selecciona *Abrir consola*.
